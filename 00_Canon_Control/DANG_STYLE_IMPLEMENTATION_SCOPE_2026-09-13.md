# DANG Style Implementation Scope — DarrenDang.com

**Status:** APPROVED IMPLEMENTATION SCOPE
**Approved by:** Darren Dang
**Date:** 2026-09-13

Darren approved rebuilding DarrenDang.com around the canonical DANG Signature Style Guide v1.0 / "Nathan's Style Guide."

This implementation scope authorizes a full public-site visual-system rebuild while preserving current content authority and publication boundaries.

## Required design system

- Cormorant Garamond: signature / house identity.
- Newsreader: philosophical/editorial voice.
- Source Sans 3: structure / navigation / body / UI.
- Deep navy, warm legacy gold, ivory/paper neutrals.
- Generous whitespace, editorial hierarchy, restrained structural typography, premium but not luxury-for-luxury's-sake.

## Implementation intent

Apply the system coherently across:

- site header and footer;
- homepage;
- interior page headers and long-form reading pages;
- Books, Ideas, Papers & Talks, Letters, The Way, D.O.T.S., The Dang Genome, About, Speaking, Explore, and related routes;
- cards, metadata, labels, buttons, forms, quotes, tables, diagrams, and responsive states.

## Boundaries

- Do not silently change philosophical canon or book prose.
- Do not retroactively alter published book Gold Masters merely to match the website.
- Do not deploy merely because implementation exists; review/merge/deployment remain distinct operations.
- Preserve accessibility, responsive behavior, public/private firewall, and SEO metadata.

This control records the approved visual rebuild scope and does not independently redefine the underlying style guide.
