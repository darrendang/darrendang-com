## Current reader-flow rule

A reader should be able to enter The Way before they understand The Way.

The homepage should therefore move from a human question to tangible expressions of the work before requiring the reader to understand the deeper architecture. Current preferred sequence:

**Hero → human question → Books / The Path Forward → Letters → philosophical cycle / The Way → practice → Ideas / Papers / The Way in Motion → Shared Wisdom / Pass Forward.**

The primary navigation should place immediately legible reader entry points before internal architecture language:

**The Way → Books → Ideas → Genome → Papers & Talks → Explore.**
