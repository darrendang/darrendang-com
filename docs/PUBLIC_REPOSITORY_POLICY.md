# Public Repository Policy

This repository is intentionally public because DarrenDang.com will be hosted on GitHub Pages using a free public GitHub repository.

## Allowed
- website application source;
- public-safe components and styles;
- approved public images and book artwork;
- publishable website copy;
- public deployment configuration;
- public CMS schemas.

## Not allowed
- private strategy/canon files;
- source résumés/application packages;
- personal phone numbers, home addresses, or private email addresses;
- unpublished family/source documents;
- API keys, credentials, tokens, or secrets;
- confidential or pre-decision notes.

A repository audit runs in CI before builds. The repository was initialized with a fresh Git history so earlier local development commits containing private project canon are not part of the public history.
